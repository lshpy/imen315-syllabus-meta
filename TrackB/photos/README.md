## 빠르게 사진 얻는 방법

1. **Google 이미지 검색** → 인물 이름 검색
2. 정면 얼굴 위주, 정사각형에 가까운 사진 선택
3. 우클릭 → **이미지 저장** → 위 파일명으로 저장
4. (선택) https://www.iloveimg.com/crop-image 에서 정사각형으로 crop

**팁:** 사진이 없어도 게임은 정상 작동합니다. 사진이 없으면 자동으로 이름이 표시됩니다.
